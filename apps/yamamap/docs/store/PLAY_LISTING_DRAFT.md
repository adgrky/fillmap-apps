### 詳しい説明(4000文字以内、ドラフト)
```
登った山が光る、自分だけの登頂史を育てよう。

「百名山埋め立てマップ」は、日本百名山100座に対応した登頂記録アプリです。
地図上の山をタップして「登頂した!」を押すだけで、波紋が広がるアニメーションとともに記録されます。

【特徴】
✓ 百名山100座対応(3000m峰13座・27都道府県)
✓ 累計標高をスコア化、「エベレストN回分」で換算表示
✓ 都道府県別・3000m峰別の達成率を確認
✓ 称号(アチーブメント)を集める楽しみ(高峰ハンター・百名山コンプリート等)
✓ 達成状況をシェア画像として保存・SNS投稿
✓ データはすべて端末内に保存。アカウント登録不要
✓ オフラインでも利用可能

【プレミアム機能(買い切り、準備中)】
広告を非表示にし、日本二百名山・三百名山の追加データを地図上に表示できるようになります。

登山好きの方はもちろん、近場の一座から少しずつ百名山を制覇していく
達成感を楽しめます。
```

## コンテンツレーティング(質問フォーム回答ドラフト)
本アプリは暴力・性的表現・ギャンブル要素を含まないシンプルな記録アプリのため、
基本的に「いいえ」で回答可能と想定。→ 想定レーティング: 全年齢(IARC 3+ / PEGI 3 等)

## データセーフティ(Data safety)フォーム回答ドラフト
- **データの収集: あり**(広告ID。AdMob配信・効果測定のため)
- 該当なし: 個人情報・位置情報・連絡先等の収集はしない
- **データの共有: あり**(広告ID → Google AdMobへ。決済情報はGoogle Playが処理し当方は取得しない)
- データの暗号化(送信時): Google提供SDK(AdMob/Play Billing)経由のため標準的に暗号化される
- データ削除のリクエスト方法: アプリ内データはすべて端末内のみ(設定画面から削除可能)
- 収集する権限: インターネット(地図タイル取得・広告配信用)

**虚偽申告はアプリ削除リスクがあるため、Play Console入力時は上記の「あり」回答を必ず使うこと。**
