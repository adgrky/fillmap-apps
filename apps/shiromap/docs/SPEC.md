# 100名城埋め立てマップ(shiromap) SPEC

> 基底: 工場マスター + シリーズ設計(§E POINT, §A4)。本書は差分のみ。yamamap骨格を流用。

## §1 概要
日本100名城の攻略記録を地図に埋めるPOINTモードアプリ。一言: 攻め落とした城を旗で示せ。

## §2 データ(§E2 / §E6 / §E7)
- ソース: 公益財団法人日本城郭協会「日本100名城」(2006)。座標は「日本百選と座標値」(shiro02.csv)。
- 前処理: `tools/curate_castles.py`(現存12天守・国宝5城タグ付与)→ `tools/preprocess_point.py`。
- 受入: 100城 / 現存12天守12・国宝5 / 47都道府県。

## §3 塗り状態
- 未攻略(グレー小円) / 攻略済(金+グロー+白縁)。visits 在不在で判定。攻略時に波紋演出(W1, 金色)。

## §4 保存
- storageKey: `shiromap.v1` / version: 1 / visits: `{[id]:{count,firstDate?,memo?}}`

## §5 画面構成
- タブ: 地図 / リスト(都道府県・ワンタップ攻略) / 年表 / 設定。城タップ→攻略トグル+攻略日/回数/メモ。

## §6 デザイントークン
- アクセント: 攻略の金(THEME #eab308 / DIM #fde047)。

## §7 スコア / 演出
- 攻略数・全国達成率・「天下統一まであと◯城」。文言は「攻略」で統一。

## §8 達成率
- 100名城 / 現存12天守 / 国宝5城 の多層。

## §9 称号
- 初陣 / 現存天守ハンター(12) / 国宝コンプ(5) / 天下の半ば(50) / 天下統一(100・金)

## §10 シェア画像
- 「100名城 N/100城、攻略。」+「現存天守 N/12」+統一フッター。

## 残課題(v2)
- 続日本100名城(101-200番)の追加(同DBに無く別途整備が必要)。旗が立つアニメの本格演出。図鑑モード(天守形式・築城年)。
