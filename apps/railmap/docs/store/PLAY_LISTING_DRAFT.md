### 詳しい説明(4000文字以内、ドラフト)
```
乗った路線が光る、自分だけの日本地図を育てよう。

「塗り鉄」は、日本全国597路線・約27,700kmに対応した鉄道乗りつぶしアプリです。
地図上の路線をタップして「乗った!」を押すだけで、その路線が光って塗りつぶされます。

【特徴】
✓ 全597路線対応(国土数値情報データ使用、新幹線・JR在来線・私鉄・地下鉄・路面等)
✓ 路線の一部だけ乗った場合も区間単位で記録できる
✓ 都道府県別・路線種別の達成率を統計画面で確認
✓ 称号(アチーブメント)を集める楽しみ
✓ 達成状況をシェア画像として保存・SNS投稿
✓ データはすべて端末内に保存。アカウント登録不要
✓ オフラインでも利用可能

【プレミアム機能(買い切り)】
広告を非表示にし、路線を新幹線・JR在来線・私鉄・地下鉄・路面の5種別ごとに
色分け表示できるようになります。自分の「乗りつぶしマップ」がより一目で
分かりやすくなります。

鉄道好き・乗りつぶし好きの方はもちろん、通勤通学路線から始めて
少しずつ地図を塗り広げていく達成感を楽しめます。
```

## データセーフティ(Data safety)フォーム回答ドラフト(AdMob+Play課金導入後・要更新)
- **データの収集: あり**
  - 広告ID(AdMob配信・効果測定のため)
  - 該当なし: 個人情報・位置情報・連絡先等の収集はしない
- **データの共有: あり**(広告ID → Google AdMobへ。決済情報はGoogle Playが処理し当方は取得しない)
- データの暗号化(送信時): Google提供SDK(AdMob/Play Billing)経由のため標準的に暗号化される
- データ削除のリクエスト方法: アプリ内データはすべて端末内のみ(設定画面から削除可能)。広告IDはOS側の「広告のパーソナライズ設定」でリセット可能、と回答
- 収集する権限: インターネット(地図タイル取得・広告配信用)

**虚偽申告はアプリ削除リスクがあるため、Play Console入力時は上記の「あり」回答を必ず使うこと**(旧ドラフトの「データ収集なし」は広告導入前の古い回答)。
