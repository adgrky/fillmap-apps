# 温泉めぐりマップ(onsenmap) SPEC

> 基底: 工場マスター + シリーズ設計(§E POINT, §A6)。shiromap骨格を流用。

## §1 概要
日本百名湯の入湯記録を地図に埋めるPOINTモードアプリ。一言: 浸かった温泉地が湯けむりを上げる地図。

## §2 データ(§E2/§E6/§E7)
- ソース: 松田忠徳『日本百名湯』。座標は「日本百選と座標値」(onsen02.csv)。
- 前処理: `tools/curate_onsen.py` → `tools/preprocess_point.py`。受入: 100湯 / 36都道府県。
- 注: 元データに泉質列が無いため、泉質別達成率はv2(別ソース突合が必要)。

## §3 塗り状態
- 未入湯(グレー小円) / 入湯済(朱+グロー+白縁)。入湯時に湯けむり風の波紋演出(W1, 朱色)。

## §4 保存
- storageKey: `onsenmap.v1` / version: 1 / visits: `{[id]:{count,firstDate?,memo?}}`

## §5 画面構成
- タブ: 地図 / リスト / 年表 / 設定。温泉タップ→入湯トグル+入湯日/回数/メモ。

## §6 デザイントークン
- アクセント: 湯の朱(THEME #fb7185 / DIM #fda4af)。

## §7 スコア / 演出
- 入湯数・全国達成率・「制覇まであと◯湯」。

## §9 称号
- 初湯 / 温泉県制覇(県100%) / 五十湯めぐり(50) / 百湯クラブ(100・金)

## §10 シェア画像
- 「百名湯 N/100湯」+「制覇まであと◯湯」+統一フッター。

## 残課題(v2)
- 泉質別達成率(泉質コレクター称号)・湯けむりパーティクル本格演出・主要温泉地300への拡張(設計書A6)。
