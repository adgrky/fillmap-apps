### 詳しい説明(4000文字以内、ドラフト)
```
走った道が光る、自分だけの日本地図を育てよう。

「国道完全制覇マップ」は、全国436路線の国道に対応した走破記録アプリです。
地図上の国道をタップして「走破した!」を押すだけで、その路線が光って塗りつぶされます。

【特徴】
✓ 全436路線対応(OpenStreetMapデータ使用)
✓ 都道府県別の達成率を統計画面で確認
✓ 称号(アチーブメント)を集める楽しみ
✓ 達成状況をシェア画像として保存・SNS投稿
✓ データはすべて端末内に保存。アカウント登録不要
✓ オフラインでも利用可能

【プレミアム機能(買い切り、準備中)】
広告を非表示にし、海上国道(フェリーで結ばれた国道)・点線国道(交通不能区間のある国道)のタグを路線情報シートで確認できるようになります。

ドライブ好き・道路好きの方はもちろん、通勤通学の国道から始めて
少しずつ地図を塗り広げていく達成感を楽しめます。
```

## データセーフティ(Data safety)フォーム回答ドラフト
- **データの収集: あり**(広告ID。AdMob配信・効果測定のため)
- 該当なし: 個人情報・位置情報・連絡先等の収集はしない
- **データの共有: あり**(広告ID → Google AdMobへ。決済情報はGoogle Playが処理し当方は取得しない)
- データの暗号化(送信時): Google提供SDK(AdMob/Play Billing)経由のため標準的に暗号化される
- データ削除のリクエスト方法: アプリ内データはすべて端末内のみ(設定画面から削除可能)
- 収集する権限: インターネット(地図タイル取得・広告配信用)

**虚偽申告はアプリ削除リスクがあるため、Play Console入力時は上記の「あり」回答を必ず使うこと。**
