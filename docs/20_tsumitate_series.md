# 積み立てシリーズ設計書(共通エンジン+全アプリ個別仕様)

> 「数値を積み上げ、成長を可視化し、未来を見せる」体験を共通エンジン化する。
> 技術基盤・デザイントークン・保存/入出力・PWA・運用ルールは railmap 基底SPEC に準拠(再記述しない)。
> モノレポ: tsumitate-apps/(packages/core + apps/*)

---

## §E. 積み立てエンジン共通仕様(packages/core)

### E1. 中核概念
すべてのアプリは「**エントリ(いつ・何を・どれだけ)を積む → 累計が育つ → 未来が見える**」の3層で構成する。

```ts
type Entry = { id: string; date: string; categoryId: string;
               amount: number;            // 分 or 円 or 件(アプリ定義)
               memo?: string };
type Category = { id: string; name: string; color: string; icon: string;
                  goal?: { amount: number; deadline?: string } };
type SaveData = { version: 1; updatedAt: string;
                  entries: Entry[]; categories: Category[];
                  settings: {...}; unlockedAchievements: {...} };
```
- 保存: localStorage(entries 5,000件まで想定。超過時は古い順アーカイブ書出を促す)
- 入出力: JSON+**CSVエクスポート**(表計算で見たい層が必ずいる)

### E2. 共通画面構成(4タブ)
1. **きろく**: 中央に巨大[+]ボタン。タップ→カテゴリ選択→量入力→完了まで3タップ以内(W4: 記録ハードル最小化)。タイマーモード(開始/停止で自動記録)はアプリ設定で有効化
2. **そだち**(メイン): ヒーロー数値(累計)+換算文言 / 積み上げ面グラフ(週・月・年切替)/ カテゴリ別内訳ドーナツ — **グラフはライブラリ不使用、SVG直書き**(基底SPEC方針)
3. **みらい**: 目標ゲージ+到達予測(直近30日ペースで外挿)「このペースなら ◯月◯日 に達成」
4. **せってい**: 基底SPEC準拠+カテゴリ管理

### E3. 積む瞬間の快感(W1・全アプリ共通)
- 記録完了時: 累計数値が**コインが積まれるように下から繰り上がるカウントアップ**(800ms)+小さな紙吹雪(達成系イベント時のみ大)
- 連続記録日数(ストリーク)を「きろく」画面上部に常時表示。途切れそうな日の挙動: **責めない**。「また今日から積めばOK」文言(継続系アプリは罪悪感で離脱する。ポジティブ設計を厳守)
- 効果音: コトッ(積む音)。Web Audio合成、ファイル不使用

### E4. マイルストーン演出(W2)
- 累計がキリ番(カテゴリ目標の10%刻み、累計100/500/1000単位)到達時に全画面お祝い(2秒、タップでスキップ)+称号解除
- 「あと少し」常設: そだち画面に「次のマイルストーンまで あと◯◯」

### E5. シェア画像(W3)
基底SPEC §10 レイアウト準拠。主役数値=累計+換算文言+面グラフのシルエット。統一フッター。

## §B1. 勉強つみたて(study)【シリーズ母体・優先度高】

**一言**: 努力を資産として積み立てる。あなたの勉強は裏切らない
### 勝ち筋
- W2換算: 「累計312時間 = 13日ぶっ通し分」「1万時間の法則まで ◯◯時間」。**「努力資産」というメタファーで通帳風の履歴表示**(摘要=カテゴリ、入金=時間)が独自性
- W3: テスト前・受験クラスタがXで「積み上げ報告」をする文化と完全一致。「今週の積立 12.5時間」画像
- W4: タイマーモード標準ON。ポモドーロ(25/5)プリセット
- W5: 科目別の時間帯ヒートマップ(あなたは夜型/朝型)、週次レポート
### 称号例
初積立 / 10時間 / 100時間 / 継続7日 / 継続30日 / 1000時間(金)
### フェーズ
P1: エンジン+記録+そだち画面 → P2: タイマー/みらい/称号/シェア/PWA
指示例: `SPEC.md §E全節+§B1を実装。エンジンはpackages/coreに置きアプリから分離`

## §B2. ギター練習つみたて(guitar)【studyの量産検証・0.5日】

**一言**: 練習時間が、あなたの腕になる
### 差分のみ
- カテゴリ初期値: 基礎練/コード/曲練/耳コピ。エントリに**曲名フィールド**追加(曲別累計が見える)
- 換算文言: 「累計◯時間 — ライブ◯本分の演奏時間」
- 称号: F攻略(自己申告)/ 100時間 / 1曲マスター(曲別10時間)
- **目的**: エンジン差し替え工数の実測。ここで掛かった時間が今後の量産見積りの基準になる
指示例: `SPEC.md §B2。studyをforkしテーマ・カテゴリ・文言差替のみ。コード変更最小`

## §B3. ちょちく(chochiku)

**一言**: 貯金の「未来の姿」を見せて、今日のガマンを楽しくする
### 勝ち筋
- W2が本体: 入金記録→現在額を**設定利回りで複利外挿したグラフ**(5/10/20/30年後)を常時表示。「いまの30万円は、年4%なら20年後65万円」/ 目標(車・旅行・住宅頭金等の絵文字付きゴール)までのゲージ
- W1: 入金時、貯金箱にコインが落ちるアニメ+残高ロールアップ
- W4: **金額は端末外に一切出ない**ことを強調(金融系は信頼が命)。金額非表示モード(電車内用)
- W5: 複数口座(目的別貯金)/「もし毎月+5千円なら」シミュレータ
### 固有ロジック
複利計算: 月次複利 `FV = PV(1+r/12)^n + PMT×{((1+r/12)^n −1)/(r/12)}`。利回りは0〜10%スライダー、既定3%。**「シミュレーションであり将来を保証しません」を必ず併記**
### 称号例
初貯金 / 10万円 / 100万円(金)/ 継続入金6ヶ月
指示例: `SPEC.md §B3。エンジン流用、amount=円。複利式はB3記載どおり実装しテスト値で検証`

## §B4. 新NISAトラッカー(nisa)【時事性◎・優先度高】

**一言**: 生涯1,800万円の枠を「埋め立てる」、投資版埋め立てマップ
### 勝ち筋
- **埋め立て心理×積み立てエンジンの融合**。1,800万円の生涯枠を1マス=10万円の180マスグリッドで表示し、入金記録でマスが光って埋まる(W1: 埋め立てシリーズと同じ快感構造)
- W2: つみたて投資枠(年120万)/成長投資枠(年240万)/年間360万の3ゲージ+「生涯枠コンプ予定: ◯年◯月」外挿
- W3: 「生涯枠 18.5%埋立」シェア画像(金額を出さず%だけ出すモードあり=SNS安全設計)
- W4: 記録は手入力(月次)。**評価額や損益は扱わない**(価格取得=維持費・誤情報リスク。入金額管理に特化と明記)
- W5: 売却時の枠復活(翌年簿価復活)ルールを正しく実装 ← 多くの人が混乱している点。ここの正確さが信頼になる
### ⚠️ 実装前確認
新NISA制度の枠復活仕様・年間枠の最新ルールを金融庁公式で確認し VERIFIED.md に記録(制度理解の誤りは致命傷)
### 称号例
初入金 / 年間枠コンプ / 100万円積立 / 生涯枠50% / 1,800万コンプ(金)
指示例: `SPEC.md §B4。180マスグリッドはfillmap的演出で。制度仕様はVERIFIED.md確定後に着手`

## §B5. 投信つみたて(toushin)

**一言**: 積立投資の歩みを、手書きの家計簿より美しく
### 勝ち筋
- W2: ファンド別の累計投資額・平均取得単価(手入力の基準価額から計算)・分配金履歴の積み上げグラフ
- W4: **自動価格取得はしない**(投信の無料安定APIなし=維持費ゼロ原則)。月1回の手入力 or 証券会社CSVインポート(SBI/楽天の取引履歴CSV形式に対応。⚠️実CSVのカラム構成を確認してからパーサ実装)
- W5: 再投資シミュレーション(分配金再投資 vs 受取の将来差)
### 位置づけ
B4(新NISA)が当たった場合の上位版として開発。単体先行はしない
指示例: `SPEC.md §B5。CSVパーサはVERIFIED.mdのカラム確認後`

## §B6. 好きなこと発見(suki)

**一言**: 心が動いた瞬間を貯金する。たまった record があなたの「好き」を教えてくれる
### 勝ち筋
- W1: 記録=「ときめきを瓶に入れる」演出(ガラス瓶に光の玉が溜まっていくホーム画面。瓶が満ちる=レベルアップ)
- W2: エントリ=「何に/どれくらい心が動いたか(♥1-5)/タグ」。蓄積で**タグ×♥加重の集計が「あなたの好き上位」を自動表示**。「あなたの心は『手作業×自然×ひとり時間』に動きやすい」型の組合せ分析(タグ共起の単純集計で実現、AI不要・ゼロ円)
- W3: 月末「今月のときめきレポート」画像(上位タグ雲+件数)
- W5: 年間振り返り(Spotify Wrapped的演出)— 12月に刺さる
### 設計注意
分析は統計表示に留め、**性格診断・心理分析を断定する文言は使わない**(「〜の傾向があるみたい」程度)
### 称号例
初ときめき / 30個の好き / タグ10種 / 365日の記録(金)
指示例: `SPEC.md §B6。タグ共起集計はcoreに汎用実装(他アプリの分析にも流用)`
