# IDEAS — 新規アプリ案の受付台帳(§7)

> 思いついたらまずここに1エントリ追記し、5分トリアージにかける。
> この台帳が「アイデアの流出を防ぐ受付窓口」。判定の物差しは下のルールで固定する。

---

## トリアージ手順(順に判定、落ちたら止める)

1. **維持費ゼロで作れるか?** No → 「却下箱」へ(理由1行を残す。環境が変われば復活あり)
2. **既存エンジン(埋め立て/積み立て/金融)に載るか?**
   - 載る → 「量産リスト」へ。下のスコアで順番を決める
   - 載らない → 「第4エンジン候補箱」へ保留。**同型アイデアが3つ溜まったら新エンジン化を検討**(1本のためにエンジンは作らない。3本作れるなら工場を建てる)
3. **勝ち筋W1〜W5のうち3つ以上を具体的に書けるか?** 書けない → 「寝かせ箱」(機能はあっても愛されない)

## スコアリング(リリース順の唯一の物差し)

```
スコア = 流用度(3:エンジンそのまま / 2:小改修 / 1:大改修)
       + 市場熱(3:シェア文化が強いクラスタあり 〜 1:不明)
       + 時事性(2:いま検索される 〜 0:常緑)
```
同点は工数が短い方を先に。

## エントリ・テンプレ(コピーして使う)

```
### アイデア名 (YYYY-MM-DD)
一言: / エンジン: 埋立|積立|金融|第4候補 / スコア: 流用◯+市場◯+時事◯=◯
勝ち筋メモ: W1: / W2: / W3:
判定: 量産リスト | 第4候補箱 | 寝かせ | 却下(理由)
```
